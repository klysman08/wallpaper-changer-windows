Features

Everything you need,
nothing you don't.

🔍

Live Preview

See the real composite before it touches your desktop. Monitor outlines are drawn over it, any screen can be zoomed to on its own, the whole thing expands to fill the window — and one click applies exactly what you are looking at.

🎬

Video Wallpaper

Play any video (MP4, MKV, WebM, MOV…) as a live wallpaper behind your desktop icons. Hardware-accelerated via libmpv, multi-monitor, aspect-correct, with optional audio.

🖼️

Collage Grid

Automatic layout with 1 to 8 images per monitor. Each screen gets its own dynamically composed wallpaper.

🖥️

Multi-Monitor

Detects all connected displays automatically. Respects exact resolution and physical position of every monitor.

🔁

Auto Rotation

Set an interval in seconds and let the app cycle through your collection non-stop — even in the background.

🎞️

Fade Transition

Every wallpaper change crossfades smoothly at 30 fps using GDI WorkerW rendering — no flicker, no abrupt cuts, no system animation artifacts.

⌨️

Global Hotkeys

Next, Previous, Stop/Start, default wallpaper, effect switching, plus full video control — play/stop, mute, and next/previous clip. Nothing is bound out of the box: assign only the shortcuts you want, and the app tells you if another program already owns one.

🪟

Window Transparency

Control any window's opacity via slider or shortcuts. Toggle with a hotkey, fine-tune with modifier+Scroll. The scroll modifier key (Alt/Ctrl/Shift/Win) is configurable.

🌍

Multi-Language

The whole interface in English, Português (Brasil), and 日本語. Switch live, and it persists across restarts.

🚀

Start with Windows

On from the first launch, and one switch away from off. A boot-time start goes straight to the tray with no window; Start minimized does the same when you open it yourself.

💾

Resumes Your Session

Rotation and the video wallpaper are remembered the moment you toggle them — from the window, the tray, or a hotkey — and come back running on the next launch.

📐

Image Fit Modes

Choose how images fill the screen: Fill, Fit, Stretch, Center, or Span — per monitor or globally.

🕹️

System Tray

Closing hides to the notification area rather than quitting. Apply, step through history, start or stop rotation, or quit — all from the right-click menu, no window needed.

⏪

Wallpaper History

Changed your mind? Navigate back through previously applied wallpapers at any time.

🖱️

CLI Support

Full command-line interface for scripting and automation. Apply, watch, and configure from PowerShell.

📦

Windows Installer

MSI and NSIS installers built by the Tauri bundler. Nothing is written to the registry at install time — starting with Windows is a switch inside the app.

🪶

Native, Not Electron

A Tauri 2 shell around the system WebView, so there is no bundled browser. The interface is React and shadcn/ui; everything touching Win32 stays in a separate Python engine.

🔓

MIT Licensed

Free for personal and commercial use. No telemetry, no ads, no account required. Ever.

Under the hood

Two processes, one job each.

The interface and the Win32 work are separated on purpose: if the engine stops, the window stays up and tells you so, and the wallpaper pipeline is the same code the CLI has always used.

Shell

Tauri 2 · React · shadcn/ui

Owns the window, the tray icon, and the global hotkeys — so a shortcut survives an engine restart and can reach the window itself. Renders in the system WebView, with no bundled browser to ship.

Rust React 19 Tailwind shadcn/ui
JSON-RPC over stdio
Engine

Python 3.11+ · Pillow · libmpv

Everything that touches Win32: composing the collage, the fade transition, the WORKERW video layer, and window transparency. Ships as a headless sidecar the shell starts and stops.

Pillow libmpv Win32 API CLI

The webview never spawns a process or touches the filesystem directly — every call goes through one command on the Rust side, and the engine answers only the methods on its own allowlist.

Installation

Up and running in two minutes.

1

Download the installer

Grab the latest Wallpaper Changer_5.1.0_x64-setup.exe from the GitHub Releases page. An .msi is published alongside it if your organisation prefers one.

Download Latest Release
2

Run the setup

Nothing is written to your registry at install time, and no runtime is required — the Python engine is bundled. Language is chosen inside the app.

3

Launch and configure

Point it at your wallpapers folder, pick a collage count, check the preview, and start rotation. It registers itself to start with Windows on that first launch — one switch in Settings if you would rather it didn't.

Requirements

Windows 10 or 11
PowerShell 
# 1. Clone the repository
git clone https://github.com/klysman08/wallpaper-changer-windows.git
cd wallpaper-changer-windows

# 2. Install the engine's dependencies
uv sync --dev

# 3. Run the desktop app (starts the engine for you)
cd desktop
bun install
bun run tauri dev

# Or build the installers, engine included
.\scripts\build_app.ps1

Command Line

Full control from the terminal.

Every feature in the GUI is also available via the CLI for scripting and automation.

Apply wallpaper immediately
PowerShell 
uv run wallpaper-changer apply
Apply with options
PowerShell 
uv run wallpaper-changer apply \
  --collage-count 6 \
  --selection random
Watch mode (auto rotation)
PowerShell 
uv run wallpaper-changer watch
Video wallpaper
PowerShell 
uv run wallpaper-changer video \
  --folder C:\Videos\live --loop
