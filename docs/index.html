Features

Everything you need,
nothing you don't.

A complete toolset for managing desktop wallpapers across any number of monitors.

Picture Adjustments New

Brightness, contrast, saturation, warmth, blur, and vignette for the whole collage. Blur and vignette are sized per monitor, so they never cross a seam.

One Opacity for Every Window New

Fade every window to the same opacity: the ones open now and every one opened later. It comes back after a restart, and quitting restores them all.

Live, Editable Preview

See the exact composite before applying. Zoom into one display, drag a picture onto another to swap them, or click one to pick a different image.

Collage Grid (1–8 Images)

Multi-image composition per monitor, with the grid worked out for portrait, landscape, and ultrawide screens.

Video Wallpaper (libmpv)

Play MP4, MKV, WebM, or MOV behind your icons. Aspect-correct, with optional sound, and brightness, contrast, and saturation applied live.

Multi-Monitor Aware

Finds every connected monitor and respects each one's resolution and position on the virtual desktop.

Background Auto-Rotation

Cycle wallpapers on a timer, at random or newest first, even with the window closed. Newest-first stays quick in folders of thousands.

Save & Gallery

Keep any collage as an image, for the whole desktop or one monitor, and put it back on the desktop from the Gallery whenever you like.

Global Shortcuts

Next, previous, rotation, effects, and video controls. Nothing is bound out of the box, so no shortcut is taken from your other apps.

Reads What It Can, Names What It Can't

Formats are recognised by content, not extension. Files it cannot decode (HEIC, AVIF, RAW) are counted and named, never silently dropped.

Start with Windows, Resume

Starts quietly into the tray, and brings rotation, the video wallpaper, and the all-windows opacity back where you left them.

Multi-Language Support

English, Português (Brasil), and 日本語 built in.

Architecture

One process, two halves.

A clean separation between modern UI presentation and native Win32 execution — without a second process between them.

Shell Layer

Tauri v2 · React 19 · shadcn/ui

Owns the window, system tray, and global hotkeys. Renders natively using the system WebView with zero bundled browser runtime.

Rust React 19 Tailwind CSS shadcn/ui
in-process dispatch
Engine Layer

Rust · Win32 · libmpv

Talks to Win32 directly: multi-monitor collage composition and picture adjustments, the WorkerW live video layer, and the window-opacity hooks.

Rust libmpv Win32 SIMD resampling
Installation

Up and running in two minutes.

Download prebuilt installers or build directly from source.

1

Download Installer

Grab the latest -setup.exe installer from GitHub Releases. After that, the app updates itself.

Download Latest Release
2

Run Setup

No external runtimes required — the engine is part of the executable, and libmpv ships beside it.

3

Launch and Enjoy

Point it at your wallpaper folder, tune the live preview, and start auto-rotation.

PowerShell 
# 1. Clone the repository
git clone https://github.com/klysman08/wallpaper-changer-windows.git
cd wallpaper-changer-windows

# 2. Run the desktop app (the engine compiles with it)
cd desktop
bun install
bun run tauri dev

# Or build distribution bundle
.\scripts\build_app.ps1
Command Line

Full control from the terminal.

The app itself is the CLI: give it a subcommand and it runs headless. Point $app at %LOCALAPPDATA%\KokoroPaper\KokoroPaper.exe.

Apply wallpaper 
& $app apply
Custom collage count 
& $app apply --collage-count 4 --selection random
Watch mode (auto rotation) 
& $app watch
Live video wallpaper 
& $app video --folder C:\Videos
Picture adjustments 
& $app apply --warmth 25 --brightness -10 --vignette 40
Effect + calmer desktop 
& $app apply --effect bw --blur 20 --contrast 15
